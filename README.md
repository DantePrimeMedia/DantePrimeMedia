# Gameplay Programmer | Unreal Engine & C++

Hi! I'm a gameplay programmer and **B.S. Game Programming & Development student at Southern New Hampshire University**, focused on building interactive systems in **Unreal Engine** using **C++ and Blueprints**.

I enjoy turning gameplay ideas into working prototypes, testing their behavior, and refining the underlying systems. My portfolio includes interaction puzzles, projectile and visual-effects experiments, procedural terrain, and survival and building mechanics.

## Featured projects

### [Locked Doors — Unreal Interaction Puzzle](https://github.com/DantePrimeMedia/Unreal-Interaction-Puzzle)
A Blueprint-based Unreal Engine 5.4 interaction and puzzle prototype. Explore the repository for project screenshots, implementation details, and testing notes.

### [C++ Gameplay & Visual Effects Experiments](https://github.com/DantePrimeMedia/Unreal-CPP-Gameplay-Experiments)
An Unreal Engine 5.4 collection featuring **color-synchronized projectile impacts, dynamic materials, Niagara effects, linked portals, and procedural terrain deformation**. Includes C++ source, screenshots, and a demonstration video.

### [C++ Survival & Building Prototype](https://github.com/DantePrimeMedia/Unreal-CPP-Survival-Prototype)
An Unreal Engine 5.7 prototype with **health, hunger, stamina, resource gathering, inventory tracking, building placement, and objective progression**. Includes C++ source, screenshots, and gameplay footage.
